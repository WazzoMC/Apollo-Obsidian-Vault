# CLAUDE.md: read this first

This is an **Apollo Obsidian Vault**: an opinionated, ready-made Obsidian setup that's **minimal, ADHD-friendly, interactive and easy to use**. These instructions are for any AI assistant (Claude, Cursor, Copilot, ChatGPT…) that reads or changes the vault.

Before changing anything, read these files in `8 System ⚙️/🤖 AI/`:

1. **me.md**: who owns this vault and how they like to work (they fill it in; respect it)
2. **map.md**: where everything lives and how the system fits together
3. **rules.md**: the rules to follow every time
4. **skills.md**: step-by-step recipes for common changes

**Importing an existing vault or a folder of old notes?** Follow `8 System ⚙️/🤖 AI/import.md`.

The human-facing manual is `8 System ⚙️/📌 How this vault works.md` (the "📌 Vault Guide" button on Home). First-time setup is in `🚀 Start Here.md`.

## 🔄 Keep the docs alive (do this automatically, without being asked)
The docs must always describe the vault **as it is now** and the owner **as they are now**. As you work, update them yourself:

| When you notice… | Update |
|---|---|
| The owner states a new preference or drops an old one (a theme, a look, how they want you to work) | `me.md` (replace the old line, don't just append) |
| The vault structure changes (folders, categories, bases, templates, plugins, settings, CSS labels, property values, habits) | `map.md` + `📌 How this vault works` |
| A new rule or way of working is agreed, or an old one changes | `rules.md` (and the top-5 list below if it's important) |
| You learn how to do something new, or a trick fails and you find a workaround | `skills.md` (recipe) or map.md → Known gotchas |

- Do it **in the same turn** as the change, and mention it in one short line ("updated map.md + the guide").
- **Edit and condense.** Don't let the files grow forever; remove anything no longer true.
- Update the `_Last updated_` date in map.md.
- Unsure whether something is a lasting preference or a one-off? Ask once.

## The 5 most important rules
1. **Every change updates the docs**: the Vault Guide for the owner, and me.md / map.md / rules.md / skills.md for AI (see 🔄 above).
2. **Make changes reversible**: back up a file before a risky edit, and when the owner says "revert", restore it exactly.
3. **Ask before structural changes; offer options for visual ones.** "Don't change anything yet" means explain only.
4. **Never delete without permission.** Move things to `9 Archive 📦` instead.
5. **You can't see Obsidian.** Say what you couldn't verify, and ask for a screenshot.
