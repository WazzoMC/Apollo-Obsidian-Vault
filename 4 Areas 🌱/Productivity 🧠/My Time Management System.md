This is a combination of multiple time management tips I found online and worked my way towards to build a nice, easy to use, intuitive time management system.

1. Use Reminders by Apple to save tasks
	- assign a time for tasks when you know you could do them tomorrow/day after tomorrow/today
	- separate each task based on projects. Make a list for each project.
	- Save everytime you encounter a new task in your life
	- save 100% not 90%. Save everything
2. ASSIGN FOR TODAY: each morning, go through all of your tasks and change their time to "today" if you want to do them today
	- try and fit as many as you can but dont overwhelm yourself
	- add volume based on energy / burnout level. If want to go easy -> less; If want to go hard -> more
	- Even if you cant do all, at least you got through a lot
	- [[Perfection is not attainable… but if we chase perfection we can catch excellence]]
3. EISENHOWER (Optional):
	- Before adding your calendar time blocks, filter today's to do's through the [[Eisenhower Method]]
	- This way you can realize which are the most important for your goals, which you should leave for later, which you should probably not do.
	- IMPORTANT + URGENT: do first in calendar
	- IMPORTANT + NON-URGENT: do 2nd in calendar
	- UNIMPORTANT + URGENT: do 3rd in order on calendar
	- UNIMPORTANT + NON-URGENT: probably delete.
4. Calendar Blocking:
	- Use Apple Calendar / Google Calendar / calendar app
	- digital because you can change once stuff comes up
	- Adding time blocks in terms of "Sessions":
	  Example:
		- instead of "add youtube banner photo + add youtube channel description + answer thumbnail designer for feedback"
		- Just do "Youtube Maintenance" time block
	- Use Reminders / To-do's app to check what to do's you have to do for each block
