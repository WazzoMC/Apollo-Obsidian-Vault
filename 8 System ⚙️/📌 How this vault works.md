## 🧠 The idea in 1 minute
Apollo mixes three popular ways of organizing notes, so you don't have to pick one:
- **Folders (PARA)**: every note has one home folder you can see: Projects, Areas, Archive…
- **Links (Zettelkasten)**: notes link to each other, and your own ideas (🌲 Evergreen) grow out of what you read.
- **Categories + Bases**: every note says what *kind* of note it is, and live tables/galleries (Bases) collect them automatically.

You never fill these in by hand. **Templates do it for you.** You mostly just pick from short lists.

## ⭐ The main workflow
**Every new note starts with one shortcut: `Cmd+Option+Shift+N`** (`Ctrl+Alt+Shift+N` on Windows/Linux). You don't need `Cmd+N`, and you never have to pick a folder.

1. Press `Cmd+Option+Shift+N`.
2. **Pick what kind of note it is:**

| It's… | Pick |
|---|---|
| Notes on something from the internet or someone else (a video, article, podcast, lecture, book chapter) | 📚 **Source Template** |
| A small fact or how-to you'll want to find again | ⚛️ **Atomic Template** |
| Your own idea or conclusion | 🌲 **Evergreen Template** |
| Something you're writing (essay, script, article, or anything you just want to write down) | ✍️ **Writing Template** |
| A meeting | 🤝 **Meeting Template** |
| A person, creator or organisation | 👤 **Person Template** |
| Something with a finish line | 🎯 **Project Template** |
| Something you look after, no end date | 🌱 **Area Template** |
| A course or class | 🎓 **Course Template** |

3. **Pick the area or project it belongs to** (one or more), then **✅ Done**. Not sure? **⏭️ Skip** and it waits in 📥 Inbox.
4. **Type a title.** That's it: the note gets its properties, moves into that area's or project's folder, and shows up on its page.

The only exceptions: **books, movies, shows, anime, manga and games** come from their search buttons (📖+, ⭐, 🎮 in the left ribbon, see 📖 Bookshelf), and **daily notes** come from **☀️ Today** on Home. Course modules and chapters come from the **➕ buttons** on the course page.

Skip the Daily, Weekly, Book, Movie, Anime, Manga, Game and Module/Chapter templates in the list: they're used automatically.

## 🗺️ The folders
Numbered so they always stay in this order:

| Folder | What goes in it |
|---|---|
| `1 Inbox 📥` | Notes you haven't filed yet (you picked ⏭️ Skip). Empty it once a week |
| `2 Journal ☁️` | `Daily ☁️` notes (one per day) and `Weekly 🗓️` notes (weekly review) |
| `3 Projects 🎯` | Things with a finish line (launch a website, plan a trip, write an essay) |
| `4 Areas 🌱` | Things you look after with no end date (health, coding, work, money) |
| `5 Evergreen 🌲` | Your own ideas and conclusions, one per note |
| `6 Bookshelf 📖` | Books, manga, movies, shows, anime, games |
| `7 People 👥` | One note per person, creator or organisation |
| `8 System ⚙️` | The machinery: templates, bases, categories, scripts, images, AI docs, clippings. Look, but you rarely need to touch it |
| `9 Archive 📦` | Finished projects and old stuff. Drag a folder here when you're done with it |

Every project and area is a **folder with a page of the same name** inside it, e.g. `4 Areas 🌱/Coding 💻/Coding 💻.md`. That page is its dashboard.

## 🧭 Where does a note go?
Ask these in order and stop at the first "yes":

1. **Has a finish line?** → a 🎯 Project (`3 Projects 🎯`)
2. **Mine to look after, no end date?** → a 🌱 Area (`4 Areas 🌱`)
3. **A book, movie, show, anime, manga or game?** → 📖 Bookshelf (use the search plugins)
4. **My own idea or conclusion?** → 🌲 **Evergreen Template**. Title = the idea itself, e.g. *"Your brain is for having ideas, not for holding them"*
5. **Notes on someone else's video, article, podcast or lecture?** → 📚 **Source Template** → files itself into the area/project you pick
6. **One small practical thing to find later** (a setting, a shortcut, "how to X")? → ⚛️ **Atomic Template** → same picker
7. **Something I'm writing** (essay, script, article)? → ✍️ **Writing Template** → same picker
8. **Taking a course?** → 🎓 **Course Template** (see 🎓 Courses)
9. **A meeting?** → 🤝 **Meeting Template**. **A person?** → 👤 **Person Template**
10. **Not sure, or no time?** → any template + **⏭️ Skip**. It waits in 📥 Inbox and you sort it later

> [!note] There's no "Resources" or "Library" folder
> Notes about a topic live **inside** that topic's area or project. Your coding video notes sit in `Coding 💻`, so opening Coding shows *everything* about coding.

## 🧩 Note types and topics
Every note answers three questions:

| | Question | Example | Who fills it in |
|---|---|---|---|
| **folder** | Where does it live? | `4 Areas 🌱/Coding 💻` | the template moves it |
| `categories` | What *kind* of note is it? | `[[📚 Sources]]` | the template |
| `topics` | What is it *about*? (one or more) | `[[Coding 💻]]`, `[[Productivity 🧠]]` | you, by picking from a list |

**The note types** (each has a page under 🗂️ Categories on Home):

| Type | What it is |
|---|---|
| 🎯 Projects | Something with a finish line |
| 🌱 Areas | Something you look after, no end date |
| 📚 Sources | Your notes on someone else's content |
| ⚛️ Atomic | One small practical fact or how-to |
| 🌲 Evergreen | Your own idea; title = the idea |
| ✍️ Writing | Something you're writing, with a `kind` and a `stage` |
| 🤝 Meetings | Meeting notes with `date` and `people` |
| 👥 People | A person, creator or organisation |
| 📰 Clippings | Articles saved from the web |
| 🎓 Courses · 🧩 Modules · 📑 Course Chapters | A course and its parts |
| 📖 Books · 🗯️ Manga · 🎬 Movies & Shows · 🍥 Anime · 🎮 Games | Your shelves |

**One note, many places.** A project or area page lists a note if the note is **in its folder**, **links to it**, *or* **has it in `topics`**. So a note about "AI for productivity" can live in Coding and still show up on the Productivity page.

## ✍️ Making notes
- **Always start with `Cmd+Option+Shift+N`** → pick a template (see ⭐ The main workflow). Templates ask you a few questions:
	- **The topic picker** (Source, Atomic, Writing, Evergreen, Meeting): a list of your areas and projects pops up. Pick one or more, then **✅ Done**. The note gets them in `topics` and **moves into the first one's folder** (Evergreen notes always go to `5 Evergreen 🌲` instead). **⏭️ Skip** leaves it in the Inbox.
	- **Untitled?** It asks for a title.
- **Person** notes go to `7 People 👥`, and **Evergreen** notes to `5 Evergreen 🌲`, automatically.
- **Automatic templates**: a new note made *inside* `5 Evergreen 🌲`, `7 People 👥` or a bookshelf folder gets the right template by itself.
- **Notes open in Reading view.** Press `Cmd+E` to edit. Daily and weekly notes always open in Reading view, so the tracker is ready to tap.

## 🎯 Projects
**New project**: `Cmd+Option+Shift+N` → **🎯 Project Template** → type a name (tip: end it with an emoji, like `Website Launch 🚀`). You get `3 Projects 🎯/<name>/<name>.md`.

The project page has:
- **🎯 Goal**: what does "done" look like?
- **➡️ Next step**: one concrete action
- **📄 Notes**: every note in the folder, linked to it, or with it in `topics`, in tabs (see 🌱 Areas)

Properties:
- `status`: `🟢 active` · `⏸️ paused` · `✅ done`. Only 🟢 active projects show on Home (🎯 Projects Now).
- `deadline`: shows under the project's tile on Home (📅 Oct 30)
- `icon`: the folder icon on Home, e.g. `[[ef-folder-orange.png]]` (colours below)

**Finished?** Set `status: ✅ done` and drag the folder into `9 Archive 📦`.

## 🌱 Areas
**New area**: `Cmd+Option+Shift+N` → **🌱 Area Template** → name → "Show it on Home?" You get `4 Areas 🌱/<name>/<name>.md`.

- `home: yes` → it shows on Home (🌱 Home Areas). `home: no` → only on the 🌱 Areas page (Home → **More areas →**). Keeps Home short.
- `cover`: the picture on its card. `banner`: the wide image at the top of its page. Drop an image into the vault and set `cover: "[[my-image.jpg]]"`.

**The area/project page tabs** (the `📄 Notes` section):

| Tab | Shows |
|---|---|
| Notes | everything |
| 📚 Sources | your notes on others' content |
| 🎬 Videos | Source notes with a YouTube link in `source`, shown as thumbnails (needs internet) |
| ⚛️ Atomic | small how-tos |
| ✍️ Writing | your writing |
| 🌲 Evergreen | your ideas |
| Recent | last edited first |

## 📚 Sources, ⚛️ Atomic, 🌲 Evergreen, ✍️ Writing
The four note types you'll make most. All come from `Cmd+Option+Shift+N`.

- **📚 Source**: notes on a video, article, podcast, lecture or book chapter. Paste the link into `source`. YouTube links get a thumbnail in the 🎬 Videos tab.
- **⚛️ Atomic**: one small thing you'll want to find again ("Hidden files on macOS: `Cmd+Shift+.`"). Short, one idea, easy to search.
- **🌲 Evergreen**: *your* idea, in your words. The title is the idea as a sentence. Link the sources it came from. Evergreen notes show related notes (ones sharing links) at the bottom. They stay flat in `5 Evergreen 🌲`.
- **✍️ Writing**: essays, scripts, articles, drafts. The template asks what `kind` it is: `essay` · `script` · `article` · `other`. Then track the `stage`: `💡 idea` → `✏️ draft` → `🔁 revising` → `✅ final`.

The idea: **Sources** are what you take in, **Atomic** notes are the facts you keep, **Evergreen** notes are what you think, and **Writing** is what you make from it.

## 🎓 Courses
For online courses, classes, bootcamps. Three levels, shown by folders:

```
🎓 Course          Boot.Dev Backend-Path ⚙️
 └ 🧩 Module         Learn Python for Beginners by Boot.dev
    └ 📑 Chapter       Variables – Learn Python for Beginners by Boot.dev
       └ ⚛️ Atomic notes you make from it
```

1. **New course**: `Cmd+Option+Shift+N` → **🎓 Course Template** → name → pick the area it belongs to. It creates `<area>/<course>/<course>.md`.
2. **Add a module**: on the course page click **➕ Module**. (A simple course can skip modules: add chapters straight to the course.)
3. **Add a chapter**: on the module page click **➕ Course Chapter**. Write your lecture notes under `## 📝 Notes`.
4. **Save a fact from a chapter**: on the chapter page click **➕ Atomic note**. It saves next to the chapter, links back to it (`from`) and shows up on the chapter, module, course and area.

- Buttons already know where you are, so they only ask for a name. **⬆️** takes you up one level.
- `order` (1, 2, 3…) fills itself in. Change it to re-sort.
- Give the course and each module a `banner`. New chapters copy their module's banner.
- 🟢 active courses show on Home next to projects. Set `status: ✅ done` to hide one.
- `topics` is always the *subject* (Coding, Python), never the course itself.

## ☀️ Daily and weekly notes
**Daily note** (`Cmd+Shift+D` or **☀️ Today** on Home), saved as `2 Journal ☁️/Daily ☁️/YYYY-MM-DD`:
- The **habit tracker** for that day (tap to tick)
- **🌙 Tomorrow's Top 3**: tonight, write the 3 things that matter most tomorrow. Tomorrow morning they show on Home as 🎯 Today's Top 3.
- **📝 Notes**, **✅ To-do**, and **🔗 Notes from today** (every note that links to this day)

**Weekly note**: open the **Calendar** in the right sidebar and click a **week number**. Saved in `2 Journal ☁️/Weekly 🗓️`:
- The week's habit grid and summary
- A 15-minute **weekly review** (what went well, what got in the way, next week's Top 3)
- A short **reset** checklist (empty the Inbox, check projects…)

## 🔁 Habits
Everything about habits lives on [[🔁 Habits]] (button on Home).

**Set your habits**: edit the **✏️ My habits** table on that page. That table *is* the tracker:

| Column | Fill in | Example |
|---|---|---|
| Habit | emoji + short name | `🧘 Meditate 5 min` |
| Property | where it's saved in daily notes. Optional (made from the name) | `meditate` |
| Goal | empty = ✅ tick box · a number = number habit | `≥ 6000` · `≤ 3h` · `5 km` |
| Days | empty = every day | `Mon Wed Fri` · `weekdays` · `weekends` |
| Minimum | ✅ = part of your Minimum Day | ✅ |

> [!warning] Don't rename a Property once you've started
> Old days are saved under that name. Rename the **Habit** column as much as you like, but leave **Property** alone.

**How it works**
- **✅ Minimum Day**: mark the few habits that make a day "good enough". Do those and the day gets its ✅. Everything else is a bonus. On a day with none of them scheduled, it's a 🌴 rest day.
- **Log**: tap the chips in today's note or on 🔁 Habits, or click a square in the week grid on Home. Number habits: type `5200`, `5.2k`, `3.5` or `3h30`.
- **Forgot a day?** Click its square in the week grid.
- **Never miss twice**: after a missed day, Home shows a ⚠️ banner. Two in a row → 🧯 rescue day (just the minimums).
- **Streaks, rates and a 20-week heatmap** live on the 🔁 Habits page.
- A typo in the table (like a bad day name) shows a ✏️ warning at the top of the tracker instead of breaking it.

## 📖 Bookshelf
Open **📖 Bookshelf** from Home for everything you're on right now, plus a button for each shelf.

**Adding things** (each saves a note with cover, details and a place for your thoughts):

| To add | Do this | Lands on |
|---|---|---|
| 📖 A book | 📖+ icon in the left ribbon, or `Cmd+P` → **New book note** | 📖 Books |
| 🗯️ A manga | Same as a book, then change `categories` to `[[🗯️ Manga]]` | 🗯️ Manga |
| 🎬 A movie or TV show | ⭐ icon in the left ribbon, or `Cmd+P` → **Create new movie note** | 🎬 Movies & Shows |
| 🍥 An anime | Same as a movie (anime is on TMDB too), then change `categories` to `[[🍥 Anime]]` | 🍥 Anime |
| 🎮 A game | 🎮 icon in the left ribbon, or `Cmd+P` → **Create new game note** | 🎮 Games |

> [!info] Movies and games need a free key
> See [[#🔑 API keys (movies and games)]]. Books work without one.

**Your shelf, your way**
- `status`: `🔖 want` · `▶️ on it` · `✅ done` · `❌ dropped`. Everything `▶️ on it` shows on Home (📖 On my shelf).
- `rating`: 1–5, shown as ★ under the cover
- **Series**: give each film or book the same `series` name (e.g. `Spider-Man`) and they sit together. `order` (1, 2, 3…) sets their order.
- **TV shows and anime** have no single director, so fill `creator` (the show's creator, or the studio) and it shows under the cover.
- Shelves sort by **category**, not folder: a manga can stay in the books folder and still show on the Manga shelf.

**Game guides and tips**: notes about a game (a guide, a build, tips from a video) show on that game's page under 🕹️ Guides & tips. Make one with the 📚 Source or ⚛️ Atomic template: your games appear in the topic picker (🎮), and picking one files the note under it. Or use the **🕹️ Game Guide Template**.

## 👥 People, 🤝 Meetings, 📰 Clippings
- **👥 People**: `Cmd+Option+Shift+N` → **👤 Person Template** → type the name. It goes to `7 People 👥` and lists every note that links to that person. Great for authors, creators, colleagues.
- **🤝 Meetings**: `Cmd+Option+Shift+N` → **🤝 Meeting Template** → pick the project or area → name it. It files itself there, dated today. Fill `people` with links to people notes.
- **📰 Clippings**: articles saved from the web with the free [Obsidian Web Clipper](https://obsidian.md/clipper) browser extension. In the extension's settings, set **Note location** to `8 System ⚙️/Clippings 📰`. Everything in that folder shows on the 📰 Clippings page. Worth keeping? Turn it into a Source note.

## 🔑 API keys (movies and games)
Each person uses their **own free key**. Never paste a key into a note.

**🎬 Movie Search** (movies, TV shows and anime): a **TMDB API key**
1. Make a free account at [themoviedb.org](https://www.themoviedb.org/signup).
2. Profile picture → **Settings** → **API** → request a key (type: *Developer*, personal use). Fill in the short form.
3. Copy the **API Key** (the short one, not the long "Read Access Token").
4. Obsidian → Settings → **Movie Search** → paste it into **API key**.

Without a key you get about 10 free searches.

**🎮 IGDB Game Search** (games): a **Twitch Client ID + Client Secret**. IGDB belongs to Twitch.
1. Log in at [dev.twitch.tv/console](https://dev.twitch.tv/console) (a free Twitch account; you may need to turn on two-factor login).
2. **Register Your Application**:
	- Name: anything unique, e.g. `obsidian-games-yourname`
	- OAuth Redirect URL: `https://localhost`
	- Category: **Application Integration**
	- Client Type: **Confidential**
3. Open the app (**Manage**) → copy the **Client ID** → click **New Secret** and copy the **Client Secret**.
4. Obsidian → Settings → **IGDB Game Search** → paste both.

**📖 Book Search**: no key needed.

## 🎨 Look and themes
- **Theme**: **Minimal** (the default, and what every custom look is built for). **Omarchy** and **Shiba Inu** are installed too: Settings → Appearance → Themes. Other themes work, but the shelves and buttons look best on Minimal.
- **Colours**: Settings → **Minimal Theme Settings** → pick a light and a dark **colour scheme** (Flexoki, Catppuccin, Everforest…). Buttons, rims and glows follow the scheme's accent automatically, in light and dark mode. The habit tracker keeps its own red/green because there the colour *means* something.
- **Banners**: any note can have a `banner` (an image at the top). **Covers**: the pictures on area cards.
- **Widths**: Home and the shelves use the full window (`max`). Project and area pages are `wide`.
- All custom styling lives in one file, `.obsidian/snippets/bookshelf.css`.

**Style labels**, for when you build your own pages:

| Label | How | What it does |
|---|---|---|
| `buttons` | callout `> [!buttons]` | turns the links inside into pill buttons |
| `tiles` | callout around a base | desktop-style folder icons (uses `icon`) |
| `gallery` | callout around a base | picture cards (uses `cover`) |
| `bookshelf` | callout or `cssclasses` | book-cover look, ★ ratings |
| `gameshelf` · `mangashelf` · `animeshelf` · `movieshelf` · `postershelf` | `cssclasses` next to `bookshelf` | game cases · manga paperbacks · streaming posters · mixed |
| `dashboard` | `cssclasses` | rounded cards for a dashboard page |
| `max` · `wide` | `cssclasses` | full-width · wider page |

A callout label wraps one embed, and the box itself is invisible:
```
> [!gallery]
> ![[Areas.base]]
```

## 🛠️ Customizing
- **New writing kind** (e.g. 🎤 speech): open `✍️ Writing Template`, find the line with `suggester`, and add your kind to **both** lists: `["📝 essay", …, "🎤 speech"]` and `["essay", …, "speech"]`.
- **New writing stage** (e.g. 👀 feedback): just type it into a note's `stage`. Obsidian suggests it from then on.
- **Reorder the category cards on Home**: each category page (`8 System ⚙️/Categories 🗂️`) has an `order` number. Lower comes first, and decimals work (`1.5`).
- **Templates** live in `8 System ⚙️/Templates 📎` and always end in **Template**, so they never share a name with a category page (two notes with the same name make links open the wrong one). Keep that rule for your own.
- **Bigger changes** (a new note type, a new shelf, a new look): ask an AI with access to the vault (see 🤖 below). The recipes are in `8 System ⚙️/🤖 AI/skills.md`.
- **Renaming a numbered top-level folder** breaks the templates and plugin settings that point to it. Avoid it, or ask an AI to rename it everywhere.

## 💾 Backups and sync
Your notes are plain text files in a folder, so any backup works. Some tips:

- **Obsidian Sync** (paid) keeps your phone and computer in step.
	- ⚠️ **Adding a new device**: turn Restricted mode **off** and set its Sync settings **before** the first sync. A fresh device with plugins off can sync its empty plugin list and switch your plugins off everywhere.
	- Sync skips files over **5 MB** (keep banners small) and needs **Sync all other types** on, or the habit tracker's script won't reach your phone.
	- Don't put the vault in **iCloud Drive or Dropbox** *and* use Obsidian Sync. Two sync systems on one folder fight.
- **Git / GitHub** (free, version history): the **Git** plugin is included. Command palette → **Git: Commit-and-sync**. It only backs up when you tell it to. Make the repo **private**, because your API keys live in the plugin settings.
- The **File recovery** core plugin keeps local snapshots of each note (Settings → File recovery).

## 🤖 Using AI with this vault
The vault is **AI-ready**. Any AI that can read files (Claude, Cursor, ChatGPT with file access…) can understand it:
- `CLAUDE.md` (in the vault's main folder) is the AI's starting point.
- `8 System ⚙️/🤖 AI/` holds what it needs:
	- **me.md**: about *you*. Fill it in so the AI knows how you like to work.
	- **map.md**: how the vault is built.
	- **rules.md**: rules it follows (ask before big changes, never delete, keep this guide up to date…).
	- **skills.md**: step-by-step recipes for common changes.
- Try: *"Read CLAUDE.md, then add a 🎙️ Podcasts shelf"* or *"Add a habit for drinking water"*.

## 🧳 Bring your old vault
Already have notes in another Obsidian vault (or any folder of Markdown files)? An AI can sort them into Apollo for you in one go: projects, areas, courses, sources, daily notes and all.

1. **Copy, don't move.** In Finder or Explorer, make a folder `📦 Import` inside `1 Inbox 📥`, and copy your old vault's folders into it. Leave out its hidden `.obsidian` folder (old settings). Your old vault stays exactly as it was.
2. **Open an AI that can work with files** in this vault (see below) and paste:
	> Read CLAUDE.md, then import my old notes by following `8 System ⚙️/🤖 AI/import.md`. They're in `1 Inbox 📥/📦 Import`.
3. **Wait.** The AI looks through everything, then files each note in the right place:
	- class folders become 🎓 courses and lectures become 📑 chapters
	- readings become 📚 sources and definitions become ⚛️ atomic notes
	- journal entries become ☀️ daily notes
	- deadlines become 🎯 projects
	- ongoing subjects become 🌱 areas

	It keeps your properties and tags, and fixes links that would break.
4. **Check the log.** `1 Inbox 📥/📦 Import/📦 Import log.md` lists everything it did, what it wasn't sure about, and what to look at. Notes it couldn't place stay in `📦 Import` for you to sort.

- **Want to see the plan first?** Add *"plan first, don't move anything yet"* to the prompt. It writes the plan into the log and waits for your "go".
- **Changed your mind?** Ask the AI to *"undo the import"*. Every move is logged, so it can put everything back.

**Which AI?** Any assistant that can read and write files in a folder:
- **Outside Obsidian**: the Claude desktop app (give it access to the vault folder), Claude Code, Cursor, Codex…
- **Inside Obsidian**: an agent plugin, e.g. **Claudian** (runs Claude Code or Codex in a sidebar; needs one of them installed and a subscription or API key) or **Copilot for Obsidian** (its agent mode is a paid tier). They aren't included in Apollo, because each needs your own account.

**No AI?** Copy your folders into `1 Inbox 📥` and sort as you go: when you open an old note, move it to its project or area (`Cmd+M`) and add a `categories` property, or just leave it. Search (`Cmd+O`) finds it either way.

## 🧯 Troubleshooting
| Problem | Fix |
|---|---|
| Home shows code instead of a dashboard | Plugins are off: Settings → Community plugins → turn on, then restart. See [[🚀 Start Here]] |
| The habit tracker is empty or shows an error | Settings → Dataview → **Enable JavaScript queries** on. Check the ✏️ My habits table on [[🔁 Habits]] |
| A new note shows `<%* … %>` code | Settings → Templater → **Trigger Templater on new file creation** on (once per device) |
| Buttons (☀️ Today, ➕ Module…) do nothing | Meta Bind plugin is off, or restart Obsidian once |
| Movie or game search fails | Missing or wrong API key (see 🔑) |
| Shelves look like plain tables | Settings → Appearance → CSS snippets → `bookshelf` on |
| A card has no picture | Set its `cover` (areas) or `icon` (projects) |
| Plugins switched off on every device | A new device synced with plugins off. Turn them back on (and see 💾 Backups) |
| YouTube thumbnails don't show | They need internet, and `source` must be a YouTube link |
